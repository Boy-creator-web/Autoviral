FAQ - Pertanyaan yang sering ditanyakan

Apakah saya harus bicara dengan sales dulu?

Tidak. Flow kami full autonomous: lihat paket, pilih, checkout, bayar, dan sistem langsung memproses flow Anda. WhatsApp hanya untuk bantuan opsional.

Bagaimana saya tahu paket mana yang cocok?

Di halaman Harga, setiap paket punya kuota video/campaign/scraper. Jika masih ragu, gunakan Enterprise page untuk estimator kebutuhan.

Pembayaran seperti apa?

Checkout membuat subscription + payment record otomatis. Anda dapat memakai provider yang tersedia dan menerima invoice dari sistem.

Setelah bayar, apa yang terjadi?

Sistem langsung membuat action campaign awal dan flow operasional untuk eksekusi. Anda tinggal memantau hasil dan report periodik.

Bagaimana laporan hasilnya?

Report tersedia dari pipeline backend: action - result - report. Setiap aktivitas dan pembayaran tercatat untuk audit.

Apakah data saya aman?

API dilengkapi auth token, rate limiting, audit logging, webhook idempotency, dan monitor endpoint untuk menjaga reliability.
