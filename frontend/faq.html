Frequently Asked Questions

Jawaban cepat untuk hal penting sebelum Anda memutuskan paket.

Apakah saya harus setup teknis sendiri?

Tidak. Tim kami bantu onboarding, setup awal campaign, dan integrasi sesuai paket yang dipilih.

Berapa lama sampai campaign jalan?

Rata-rata 1–3 hari untuk setup dasar. Flow lanjutan bergantung kebutuhan integrasi dan approval konten.

Apakah bisa upgrade/downgrade paket?

Bisa. Paket dapat disesuaikan per siklus billing, termasuk penambahan kuota jika dibutuhkan.

Bagaimana metode pembayaran?

Saat ini tersedia invoice manual transfer. Gateway payment dapat diaktifkan sesuai kebutuhan enterprise.

Bagaimana keamanan data?

Akses API menggunakan token, audit log untuk aksi penting, dan pembatasan request untuk proteksi abuse.

Apakah ada kontrak minimum?

Umumnya per bulan. Untuk enterprise/custom rollout, kami sediakan opsi kontrak khusus.
