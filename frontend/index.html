Alur Operasional

  1. Pendaftaran user via POST /api/v1/users
  2. Pilih plan via GET /api/v1/pricing & POST /api/v1/subscriptions
  3. Pembayaran via POST /api/v1/payments
  4. Tindakan campaign via POST /api/v1/actions
  5. Generate hasil via POST /api/v1/results
  6. Laporan periodik via POST /api/v1/reports
